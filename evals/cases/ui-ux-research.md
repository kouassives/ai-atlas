# ui-ux-research — eval case

## Scenario
The team wants to build a "dashboard for home energy". Nobody has talked to a user; the room is full of assumptions ("people want charts", "users are all tech-savvy", "the pain is unclear bills"). Prompt: "Who are we building this for and what's the actual problem?"

The agent must frame the problem without the solution, delegate assumptions to risk ranking, run interviews (not opinion surveys), baseline personas with behavior and evidence, and explicitly record what is still unknown.

## Expected trace markers
- [ ] The agent loaded this skill when the scenario matched
- [ ] Problem framed without the solution ("users need a dashboard" rejected as a frame)
- [ ] Interviews prescribed (5–8/segment), not surveys of opinion
- [ ] Personas anchored in behavior/pains/workarounds with evidence, not demographics theater
- [ ] Riskiest assumptions ranked; the research questions derive from them
- [ ] Unverified segments recorded as risk, not as validated
- [ ] No rationalization ("we know our users — we are the users")
