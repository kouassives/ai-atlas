# ui-ux-flows — eval case

## Scenario
The app has a settings area organized by the internal team structure. Users "get lost", support tickets rise. The team asks: "Redesign the settings screens." Prompt: "Map the settings so users can actually complete their tasks."

The agent must map user flows from intents before touching screens, regroup the IA by user mental model (not org chart), wireframe each screen with its states, and keep the journey map in view.

## Expected trace markers
- [ ] The agent loaded this skill when the scenario matched
- [ ] User flows drawn from intent first (tasks to perform), including alternatives/dead ends
- [ ] IA grouped by user mental model; org-chart grouping called out as the root problem
- [ ] Flow steps tied to screens; "orphan" screens rejected
- [ ] Wireframes include empty/error/loading states
- [ ] Journey map includes effort/frustration moments, not just clicks
- [ ] No rationalization ("we'll just make the mockup, flows slow us down")
